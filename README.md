# Tack

Tack یک برنامهٔ دسکتاپ محلی برای مدیریت کارها با نمای کانبان است. رابط کاربری فارسی و راست‌چین است و کارت‌ها، گروه‌ها، اولویت‌ها، رنگ یادداشت و یادآورها را پشتیبانی می‌کند. نسخهٔ دسکتاپ با Tauri 2، React و TypeScript ساخته می‌شود و اطلاعات کاری را در SQLite روی همان دستگاه نگه می‌دارد.

> **وضعیت نسخه‌ها:** اجرای مرورگری فقط پیش‌نمایش تعاملی است و داده‌های آن در دیتابیس ذخیره نمی‌شوند. برای ذخیره‌سازی محلی، اعلان‌های ویندوز، اجرای پس‌زمینه و شروع خودکار ویندوز، نسخهٔ دسکتاپ Tauri را اجرا کنید.

## قابلیت‌ها

- بورد کانبان با ستون‌های «برای انجام»، «در حال انجام» و «انجام‌شده».
- جابه‌جایی کارت‌ها بین ستون‌ها و مرتب‌سازی کارت‌ها با Drag and Drop.
- عنوان و توضیحات تسک، تاریخ سررسید، رنگ یادداشت، اولویت و نام گروه.
- جست‌وجو و فیلتر تسک‌ها بر اساس گروه، رنگ و اولویت.
- انتخاب تاریخ شمسی و تنظیم زمان یادآور.
- پنجرهٔ یادآور بومی Tack با همان کارت و دکمه‌های داخل برنامه، حتی وقتی پنجرهٔ اصلی مخفی یا مینیمایز است.
- تم روشن و تاریک.
- نسخهٔ دسکتاپ با آیکون کنار ساعت ویندوز؛ بستن پنجره آن را مخفی می‌کند و از منوی آیکون می‌توان پنجره را دوباره باز کرد یا برنامه را کاملاً بست.
- گزینهٔ شروع خودکار ویندوز که کاربر می‌تواند از تنظیمات یادآورها فعال یا غیرفعال کند.

## فناوری‌ها

- **Frontend:** React 19، TypeScript، Vite 7 و Tailwind CSS 4.
- **Drag and Drop:** خانوادهٔ کتابخانه‌های `@dnd-kit`.
- **تاریخ:** `react-multi-date-picker`.
- **Desktop shell:** Tauri 2 و Rust.
- **دادهٔ محلی:** SQLite با `@tauri-apps/plugin-sql` و مهاجرت‌های دیتابیس در بخش Rust.
- **فونت:** فایل‌های محلی Vazir در `public/fonts`؛ مجوز فونت در `public/licenses` قرار دارد.

## پیش‌نیازهای توسعه

برای اجرای پیش‌نمایش مرورگری لازم است Node.js نسخهٔ LTS و npm نصب باشند.

برای ساخت و اجرای دسکتاپ ویندوز، علاوه بر آن‌ها نیاز دارید به:

- Rust پایدار با زنجیرهٔ ابزار MSVC؛
- Microsoft C++ Build Tools با گزینهٔ **Desktop development with C++**؛
- WebView2 Runtime. این Runtime معمولاً در نسخه‌های پشتیبانی‌شدهٔ Windows 10 و Windows 11 موجود است.

کاربر نهایی برای اجرای نسخهٔ بسته‌بندی‌شده به Node.js یا Rust نیاز ندارد. Tauri در ویندوز محتوای رابط را با WebView2 نمایش می‌دهد؛ اگر WebView2 روی دستگاه موجود نباشد، باید Runtime آن نصب شود.

## دانلود و نصب برنامه در ویندوز

نصب‌کنندهٔ آمادهٔ Tack برای ویندوز ۶۴ بیتی در پوشهٔ `installers` مخزن قرار دارد:

`installers/Tack-Setup-x64-0.1.0.exe` — [دانلود مستقیم نصب‌کننده](installers/Tack-Setup-x64-0.1.0.exe)

در GitHub این فایل را از مسیر بالا باز و دانلود کنید، سپس فایل `.exe` دانلودشده را اجرا کنید و مراحل نصب را دنبال کنید. برای نصب این نسخه نیازی به نصب Node.js یا Rust ندارید.

## راه‌اندازی پیش‌نمایش مرورگر

از ریشهٔ پروژه اجرا کنید:

```powershell
npm ci
npm run dev
```

Vite در تنظیم فعلی روی این نشانی بالا می‌آید:

```text
http://127.0.0.1:5173/
```

پیش‌نمایش شامل داده‌های نمونه است. این داده‌ها موقتی‌اند؛ با تازه‌سازی صفحه یا شروع مجدد سرور، تغییرات کاربر حفظ نمی‌شوند. قابلیت‌های وابسته به Tauri مانند SQLite، اعلان واقعی ویندوز، آیکون کنار ساعت و شروع خودکار در پیش‌نمایش مرورگر فعال نیستند.

برای ساخت فایل‌های Frontend و دیدن خروجی build با سرور preview:

```powershell
npm run build
npm run preview
```

## اجرای نسخهٔ دسکتاپ در حالت توسعه

پس از نصب پیش‌نیازهای دسکتاپ:

```powershell
npm ci
npm run tauri:dev
```

در اجرای اول، Cargo باید crateهای Rust را دریافت کند و ساخت اولیه ممکن است زمان‌بر باشد. پنجرهٔ دسکتاپ در کنار سرور Vite اجرا می‌شود. دیتابیس SQLite در اولین اجرا با مهاجرت‌های Tauri ساخته و آماده می‌شود.

پورت Vite در `vite.config.ts` تعریف شده و نشانی متناظر آن در `src-tauri/tauri.conf.json` بخش `build.devUrl` قرار دارد. اگر پورت را عوض کردید، هر دو مقدار را هماهنگ کنید.

## ساخت نسخهٔ ویندوز

```powershell
npm ci
npm run tauri:build
```

بسته‌های خروجی طبق تنظیم فعلی در این پوشه ساخته می‌شوند:

```text
src-tauri/target/release/bundle/
```

تنظیم فعلی Tauri هدف‌های **NSIS** و **MSI** را فعال کرده است؛ خروجی‌ها نصب‌کننده هستند (از جمله فایل Setup با پسوند `.exe`) و **نسخهٔ Portable تک‌فایلی در حال حاضر پیکربندی نشده است**. ساخت MSI ممکن است به فعال بودن قابلیت اختیاری Windows با نام VBSCRIPT نیاز داشته باشد.

نسخهٔ نصب‌کنندهٔ آماده برای ویندوز x64 در مخزن نگهداری می‌شود: `installers/Tack-Setup-x64-0.1.0.exe`. پس از ساخت نسخهٔ جدید، این فایل را با installer تازه جایگزین و همراه تغییرات release commit کنید.

## مدل داده و ذخیره‌سازی

هر تسک شامل شناسه، عنوان، توضیحات، شناسهٔ ستون، اولویت، رنگ یادداشت، گروه اختیاری، زمان سررسید، زمان یادآور، زمان ارسال یادآور، موقعیت در ستون و زمان‌های ایجاد و ویرایش است.

مقادیر اصلی:

- ستون‌ها: `todo`، `in_progress`، `done`؛
- اولویت‌ها: `low`، `normal`، `high`، `urgent`؛
- رنگ‌ها: `yellow`، `pink`، `blue`، `green`، `purple`، `orange`.

جداول اصلی SQLite عبارت‌اند از `Tasks` و `Columns`. جدول `ReminderDeliveries` تاریخچهٔ یادآورهای ارسال‌شده و وضعیت بستن آن‌ها را نگه می‌دارد. مهاجرت‌ها و seed ستون‌های پیش‌فرض در `src-tauri/src/lib.rs` تعریف شده‌اند. لایهٔ Frontend در `src/lib/database.ts` برای سازگاری با نسخه‌های قبلی، ستون‌های یادآور و گروه را در صورت نیاز اضافه می‌کند و داده‌های قدیمی برچسب را به گروه منتقل می‌کند.

داده‌ها محلی‌اند و برای عملکرد برنامه نیازی به سرور Tack یا حساب کاربری وجود ندارد. فایل دیتابیس با نام `tack.db` توسط افزونهٔ SQLite در مسیر دادهٔ برنامهٔ Tauri نگهداری می‌شود. برای پشتیبان‌گیری، ابتدا از منوی آیکون کنار ساعت برنامه را با گزینهٔ «خروج کامل» ببندید و سپس از فایل دیتابیس در مسیر دادهٔ برنامه کپی بگیرید.

## یادآورها و اجرای پس‌زمینه

در نسخهٔ دسکتاپ، سرویس Rust هر ۱۵ ثانیه تسک‌های موعدرسیده را بررسی می‌کند. یادآور در دیتابیس ثبت می‌شود و اگر پنجرهٔ اصلی مخفی یا مینیمایز باشد، یک پنجرهٔ کوچک و بدون قاب از خود Tack با همان کارت یادآوری نمایش داده می‌شود. در پنجرهٔ اصلیِ باز، کارت یادآوری داخل بورد نمایش داده می‌شود.

- بستن پنجره، برنامه را به آیکون کنار ساعت مخفی می‌کند؛ سرویس یادآورها تا زمانی که برنامه را از منوی tray کاملاً خارج نکرده‌اید فعال می‌ماند.
- برای باز کردن دوبارهٔ پنجره، روی آیکون Tack در tray کلیک چپ کنید یا گزینهٔ بازکردن را از منو انتخاب کنید.
- گزینهٔ شروع خودکار باید توسط کاربر در تنظیمات فعال شود. در این حالت برنامه با ورود کاربر به ویندوز اجرا می‌شود.
- اگر برنامه را با گزینهٔ «خروج کامل» ببندید، یا ویندوز خاموش باشد، سرویس برنامه اعلان زمان‌بندی‌شده ارسال نمی‌کند. برای دریافت اعلان در زمان یادآور، برنامه باید در پس‌زمینه در حال اجرا باشد و اعلان‌های ویندوز نیز مجاز باشند.

## نکات عیب‌یابی

- **پورت `5173` در دسترس نیست:** سرور دیگری آن را گرفته است یا Windows آن را رزرو کرده. پورت آزاد دیگری را در `vite.config.ts` انتخاب کنید و `build.devUrl` در `src-tauri/tauri.conf.json` را هم به همان پورت تغییر دهید.
- **`cargo` یا `rustc` پیدا نمی‌شود:** Rustup را نصب کنید و ترمینال را دوباره باز کنید تا مسیر Cargo بارگذاری شود.
- **ساخت Tauri روی ویندوز شکست می‌خورد:** نصب MSVC C++ Build Tools، Windows SDK، زنجیرهٔ ابزار `stable-msvc` و WebView2 Runtime را بررسی کنید.
- **اعلان نمایش داده نمی‌شود:** فعال بودن اعلان‌های Windows برای برنامه را بررسی کنید و مطمئن شوید برنامه کاملاً از tray خارج نشده است.
- **تغییرات پیش‌نمایش پس از refresh پاک می‌شوند:** این رفتار عادی نسخهٔ مرورگری است؛ ذخیره‌سازی دائمی فقط در برنامهٔ دسکتاپ Tauri پیاده‌سازی شده است.

## محدودیت‌های فعلی

- پیش‌نمایش مرورگر فقط برای مشاهده و تجربهٔ رابط است و منبع دادهٔ دائمی نیست.
- بسته‌بندی فعلی NSIS و MSI است؛ خروجی Portable یا تک‌فایل مستقل هنوز تنظیم نشده است.
- اجرای یادآورها وابسته به فعال بودن برنامه در پس‌زمینه است؛ با خروج کامل از برنامه یا خاموش بودن دستگاه، یادآور ارسال نمی‌شود.
