# Task Board

برد مدیریت تسک آفلاین و محلی، با رابط فارسی و راست‌چین. رابط با React و TypeScript ساخته شده و نسخهٔ دسکتاپ برای ویندوز از Tauri استفاده می‌کند.

## امکانات

- برد کانبان با ستون‌های «برای انجام»، «در حال انجام» و «انجام‌شده»
- جست‌وجو و فیلتر بر اساس عنوان، گروه، اولویت و رنگ یادداشت
- تاریخ شمسی و زمان یادآوری
- اعلان ویندوز و ادامهٔ یادآوری‌ها هنگام پنهان بودن پنجره، با آیکون کنار ساعت
- اجرای خودکار اختیاری هنگام ورود به ویندوز
- ذخیره‌سازی محلی با SQLite؛ داده‌ها روی دستگاه کاربر می‌مانند

## اجرا در مرورگر

```bash
npm install
npm run dev
```

اجرای مرورگری یک پیش‌نمایش تعاملی است و تغییرات آن در دیتابیس ذخیره نمی‌شوند.

## اجرای دسکتاپ و ساخت نصب‌کنندهٔ ویندوز

ابتدا Node.js، Rust و پیش‌نیازهای ساخت Tauri برای ویندوز را نصب کنید؛ سپس:

```bash
npm install
npm run tauri:dev
```

برای ساخت نصب‌کننده‌ها:

```bash
npm run tauri:build
```

Tauri نصب‌کننده‌های NSIS و MSI را در پوشهٔ `src-tauri/target/release/bundle` می‌سازد.
